A pixel game about an immortal snail

Trail

Salt won't help.

You took the deal: a million gold, and a snail that follows you forever. It is slow. It always knows where you are. If it touches you, you die. Somewhere at the end of 24 quests there is a way to make it stop.

One file, 107 KB. Runs in any modern browser on Windows, Mac or Linux. No install, no account, no internet needed.

Or play it in the browser first.

This snail is moving at its in-game speed. It will get there.

Play offline

Three steps, no install

  1. Download the file

    Press the button above. You get one file, trail.html. Everything is in it: the world, the sprites, the music.

  2. Open it

    Double-click trail.html in your downloads folder. It opens in your browser and runs without internet. Move it anywhere you like first.

  3. Play, then sleep

    The game saves when you go to bed, in the browser you opened it with. Open the same file in the same browser next time and pick Continue.

The game

Everyone in Mossbury has an idea. None of them work.

Marta sends you to buy salt. Greta blows you a glass jar. Bram sells you a pickaxe for the old ice in the peaks. Oskar says the sea takes everything. Otto has a rocket. The snail keeps coming, in a straight line, through water and over cliffs. Every failed plan costs gold, and the real way out needs all of it back.

Questions

Before you start running

How long is it?

The main quest has 24 steps. Plan on an hour, more if you pick the Dread speed on the title screen.

Where is my save?

In your browser's storage for that file. A private window forgets it, and so does clearing site data. Moving the file to another folder can start you fresh too.

Does it work on a phone?

Yes, with an on-screen stick and buttons. On a phone it is easiest to play in the browser instead of downloading.

Can I share it?

Send someone trail.html. It is a plain web page with no dependencies, so it opens anywhere a browser does.
